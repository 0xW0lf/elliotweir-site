# Changelog

## 0.1.0 — 2026-11-03

- Added a browser-only IPv4 subnet calculator with a /0–/32 CIDR slider, masks, address ranges, host counts, binary view and copy action.
- Extended Guest Risk Calculator with an optional access-review workload planner, scope selection, reviewer capacity and target-date estimates.
- Added a separate external-tool collection: CyberChef, Message Header Analyzer, VirusTotal and urlscan.io, with privacy guidance and safe new-tab links.
- Discarded the experimental Security Header Analyser before publication; no scanner API or server service is included.
- Preserved the existing CSP and browser security headers; no new dependencies or network permissions.
- Verified clean npm installation, full dependency audit (zero known vulnerabilities), production build, 18-page output checks, subnet edge cases and browser interactions. These checks are not a full penetration test or a guarantee against all vulnerabilities.
